# Vernis Nail Studio

Клиентский сайт + FastAPI backend + SQLite + админ-панель.

Главный пользовательский сценарий:
**услуга → дата → свободное время → имя/телефон → заявка → уведомление администратору.**

Выбор мастера намеренно отсутствует: запись идёт в студию Vernis как в единый ресурс.

Подробная инструкция по запуску и деплою: `README_DEPLOY.md`.
